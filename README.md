# AsatidSite Sites

مخزن مستقل خروجی‌ها و سایت‌های ساخته‌شده توسط AsatidSite.

این مخزن از هسته پلتفرم در `asatidsite` جداست تا هر سایت خروجی، هویت بصری، ساختار محتوا، assets و چرخه انتشار مستقل خود را داشته باشد.

## ساختار

- `registry/` — پایگاه مدیریت و معرفی سایت‌های استادان
- `samples/` — سایت‌های نمونه و Reference
- `professors/` — سایت‌های واقعی استادان
- `shared/` — منابع مشترک فقط در صورت نیاز
- `themes/` — تنظیمات و بسته‌های ظاهری خروجی‌ها

## اصل معماری

**ساختار مشترک، هویت مستقل.**

هسته، معماری و استراتژی در مخزن `asatidsite` توسعه پیدا می‌کند؛ این مخزن محل نگهداری خروجی‌های مستقل و قابل انتشار است.
