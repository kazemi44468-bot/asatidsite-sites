# AsatidSite Sites

مخزن مستقل خروجی‌ها و سایت‌های ساخته‌شده توسط AsatidSite.

این مخزن از هسته پلتفرم در `asatidsite` مستقل است؛ تمام HTML/CSS/JS، فونت‌ها، تصاویر و منابع لازم برای خروجی‌های قابل انتشار باید داخل همین مخزن نگهداری شوند.

## ساختار

- `index.html` — پورتال اصلی
- `registry/` — پایگاه اساتید
- `master/` — Master Academic و موتور قالب مادر
- `samples/` — سایت‌های نمونه و Reference
- `professors/` — سایت‌های مستقل استادان
- `assets/fonts/` — تمام فونت‌های محلی
- `assets/css/` — CSSهای مشترک و استانداردهای سراسری
- `assets/js/` — JSهای مشترک
- `assets/images/` — تصاویر مشترک

## استاندارد قطعی طراحی

این استاندارد برای تمام صفحات جدید و تمام سایت‌های مستقل این مخزن الزامی است:

1. زبان و چیدمان فارسی با `dir="rtl"` و طراحی Mobile First/Responsive.
2. فونت خوانای اصلی: `Vazirmatn` از `assets/fonts/`؛ بدون CDN برای فونت‌های اصلی.
3. فونت هویتی خوشنویسی: `Shekasteh V2.001.ttf` از `assets/fonts/` و استفاده انتخابی در تیترها، شعارها و عناصر هویتی.
4. هر صفحه باید در موبایل، تبلت و دسکتاپ طراحی اختصاصی و بدون overflow ناخواسته داشته باشد.
5. صفحات موبایل باید منوی پایین صفحه (Bottom Navigation) زیبا، ثابت، لمسی و شیشه‌ای داشته باشند.
6. فضای کافی در پایین صفحه برای جلوگیری از پوشیده‌شدن محتوا توسط Bottom Navigation الزامی است.
7. هر سایت استاد می‌تواند هویت بصری مستقل داشته باشد و نباید صرفاً کپی ظاهر AsatidSite باشد.
8. مسیر همه assets باید نسبت به همان صفحه و داخل همین مخزن باشد؛ ارجاع به `shared/` یا منابع خارج از این مخزن ممنوع است.
9. قبل از افزودن صفحه جدید، وجود فونت‌ها و assets محلی بررسی شود.

## اصل معماری

**ساختار مشترک، هویت مستقل.**

هسته و معماری در مخزن `asatidsite` توسعه پیدا می‌کند؛ این مخزن محل خروجی‌های مستقل، assets محلی و چرخه انتشار سایت‌هاست.
