# بانک Intro اساتیدسایت

این پوشه، کتابخانه نمونه‌های Intro برای صفحات شخصی استادان است.

## استاندارد هر Intro

هر نمونه باید تا حد امکان یک فایل مستقل باشد:

```text
intros/
├── sample-name/
│   └── index.html
├── sample-name-2/
│   └── index.html
└── ...
```

### قواعد

- هر Intro در یک فایل `index.html` نگهداری شود.
- CSS داخل همان فایل و در بخش `<style>` قرار بگیرد.
- برای نمونه‌های ساده، JavaScript خارجی استفاده نشود؛ در صورت نیاز JavaScript نیز داخل همان فایل و در `<script>` قرار بگیرد.
- نمونه نباید به CSS یا JS اختصاصی یک استاد وابسته باشد.
- مسیر ورود به صفحه اصلی استاد باید در زمان استفاده از نمونه تنظیم شود.
- ساختار Intro باید مستقل از قالب صفحات داخلی استاد باشد.
- نام پوشه کوتاه، انگلیسی و قابل تشخیص باشد.
- قبل از استفاده برای یک استاد، متن، تصویر، عنوان، رنگ و لینک ورود شخصی‌سازی شود.

## نمونه فعلی

`kazemi-classic` یک Intro آکادمیک کلاسیک با ظاهر روشن، شیشه‌ای و جزئیات طلایی است.

نمونه‌های بعدی نیز در همین بانک اضافه می‌شوند تا هنگام ساخت صفحه استاد، بتوانیم از بین چند طراحی آماده انتخاب کنیم.
